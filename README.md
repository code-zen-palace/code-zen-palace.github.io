# primekampllc.com

The website of PrimeKamp LLC, served by GitHub Pages from the root of this
repository's `main` branch (the `CNAME` file points it at primekampllc.com).
The pages are plain HTML generated by a small Python script and committed, so
Pages serves them exactly as they are. `.nojekyll` turns Jekyll off.

## Layout

| Path | What it is |
| --- | --- |
| `src/products.json` | Every product: games, TravelCharika, anything later. **One entry per product.** |
| `src/site.json` | Company name, address, email, navigation, share image |
| `src/templates/base.html` | The `<head>`, header and footer of every page |
| `src/pages/*.html` | Home, Games, About, Contact, Legal and 404, with front matter between `---` lines |
| `src/legal/<id>/*.html` | Each product's privacy, terms and delete-data text, kept word for word |
| `tools/build.py` | Renders everything above into the repo root |
| `tools/check_links.py` | Checks every link, image and `#anchor` on the built site |
| `assets/` | `site.css`, the logo files from the brand kit, the share image |
| `fonts/` | Inter (variable, SIL OFL 1.1, licence in `fonts/Inter-LICENSE.txt`) |
| root `favicon*`, `android-chrome-*`, `apple-touch-icon.png`, `site.webmanifest` | From the brand kit's `02_Favicon`, as its HOW_TO_INSTALL says |

Generated files (do not edit by hand; edit `src/` and rebuild): `index.html`,
`404.html`, `games/`, `about/`, `contact/`, `legal/`, each product's
`index.html` (`tiny-acres/`, `big-deal/`, `travelcharika/`), the six legal
pages, `sitemap.xml`, `robots.txt`.

Copied, not generated: `tiny-acres/play/` is Tiny Acres' web game (today's
acre in the browser), a Flutter web build copied here by `tools/build_web.sh`
in the tiny-acres repo. `tools/build.py` never writes there; rebuild it from
that repo, never by hand. Its own `index.html` uses the game's look, not the
site's template.

## Rebuild and preview

```sh
python3 tools/build.py            # writes the pages; prints what changed
python3 tools/build.py --check    # exit 1 if a committed page is out of date
python3 tools/check_links.py      # internal links; add --external for outside links
python3 -m http.server 8000       # then open http://localhost:8000
```

Python 3 standard library only. Links are root-absolute (`/games/`), so preview
through the server, not by opening files.

## Add a product

1. Put its icon (a square PNG, about 512 px) and any screenshots (540 × 960
   JPEG, about 100 KB: `sips -s format jpeg -s formatOptions 78 -Z 960 in.jpg --out out.jpg`)
   in a folder named after it, for example `island-rules/`.
2. Add one entry to `src/products.json`:

   | Field | Meaning |
   | --- | --- |
   | `id` | Short name, also used for `src/legal/<id>/` |
   | `name` | As people say it; `store_title` if the store name differs |
   | `kind` | `game`, `travel` or `other` (games also appear on `/games/`) |
   | `page` | Its page on this site, like `/island-rules/` |
   | `pitch` | One line; `description` a sentence or two |
   | `icon`, `screenshots` | Paths from the site root; every screenshot needs `alt` text (`"update": true` marks a picture of the `update`) |
   | `update` | Optional: something in the next update or just out: `status` (`next` or `new`), `name`, `summary` (a short clause), `text` |
   | `channels` | Where to get it: `store`, `platform`, `status`, `url` (and optional `label`, `cta`) |
   | `features`, `money` | The "What it's like" list and the "Fair and simple" note |
   | `legal` | `privacy`, `terms`, `delete_data` URLs (on this site or elsewhere) |
   | `support_email` | Shown on its page, the Contact page and the Legal page |

   `status` is one of `live` (on sale: shows the store link as the page's
   main button), `review` (waiting for the store: "Coming soon to Google Play",
   no link), `testing` (a public test listing: linked, marked as testing) or
   `coming` (being made: "iPhone: coming").
   **To launch Big Deal on Google Play**, change its channel's `"status": "review"`
   to `"live"`; the Play URL is already there.

   An `update` with `"status": "next"` shows "In the next update" on the
   product's page (its own panel), "<name>: in the next update" beside the
   store links (also on the home and Games cards), a line on the Games page,
   the meta description, and, on each picture marked `"update": true`, a note
   under it and "<name> arrives in the next update." at the end of its alt
   text. `"new"` says "New" in their place and drops the alt-text sentence.
   **When Tiny Acres 0.2.0 is in
   the stores**, change its update's `"status": "next"` to `"new"` (the one
   line for Worlds) and rebuild.
3. If its legal pages live on this site, copy each one's text into
   `src/legal/<id>/privacy.html` (and `terms.html`, `delete-data.html`) with
   front matter giving `title`, `path` (the URL, which must match `legal` in
   products.json), `product` and `doc` (`privacy`, `terms` or `delete_data`).
4. `python3 tools/build.py`, `python3 tools/check_links.py`, preview, commit.

The home page shows every product in the order of products.json, followed by
the `more_card` (delete that key to hide the "More to come" card).

## URLs that must keep working

The apps and store listings link to these; keep the paths and the legal text:
`/privacy.html`, `/terms.html`, `/delete-data.html` (Tiny Acres),
`/big-deal/privacy.html`, `/big-deal/terms.html`, `/big-deal/delete-data.html`,
and `/app-ads.txt` (AdMob). `/tiny-acres/play/` too: every result shared from
Tiny Acres links there. Also keep `icon.png`, `shots/`, `big-deal/icon.png`
and `travelcharika/icon.png`, which other places may link.

## Brand rules in one paragraph

Night first: the page is Night `#150F1F`, text Marshmallow `#FBF3EE`, cards
`#1F1829` with a `#3A2E48` hairline, secondary text `#B3A4BE`, links `#FF7A84`.
Exactly one filled Ember button (`#FF4E5B`, Night text) per screen, and Ember
only for highlights, never long text. Light sections and documents (the footer,
the legal pages) use Marshmallow with Night text, Dusk `#5C4A6E` for secondary
text and Cinder `#C92A3E` for links and buttons, because Ember fails on light.
Inter for text and Inter Display (the variable font at optical size 32) for
headlines; h1 in Display Black with -0.02em tracking. Cards round 16 px,
buttons 12 px. Use the logo files only, never retyped: the horizontal logo in
the header (`_on-dark`, or `_on-light` on light pages), the made-by logo in the
footer, keeping clear space of one P-height and the minimum sizes. Embers are a
few small pixels low beside the campfire, clear of the logo and text, and still
when the visitor asks for reduced motion. Write "PrimeKamp"; "PrimeKamp LLC"
only for legal and company details. Short, warm, plain words, and only true
claims.
